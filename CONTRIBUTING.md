# Contributing to Surasura

Thank you for sending a change. Pull requests are welcome; open an issue first for anything large.

## Before you send it

- Match the style of the file you edit; keep the change small.
- Run the tests: `python run_tests.py`.
- Never include anyone's personal data (a library, known words, Anki decks, settings).
