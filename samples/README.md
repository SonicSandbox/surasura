# The sample texts

*Try it with samples first* (setup, page 3) copies these into an empty library. Every one is free to share: the stories
are in the public domain — their authors died more than 70 years ago, and each work was already in the public domain in
its own country on 1 January 1996 (so the US never restored it); all but ごん狐 (1932) were also published before 1931 —
and the subtitle was written for Surasura and given away (CC0).

**The Aozora Bunko files** are as 青空文庫 publishes them — the title, the notation legend, the ruby 《》 and notes ［＃…］,
and the colophon (底本, 入力, 校正, the 青空文庫作成ファイル note), which Aozora Bunko asks to be kept
([取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)). The changes, both of the kind those terms allow (a file
format, a note's form): Shift_JIS to UTF-8 with LF line ends; and in 蜘蛛の糸 the 外字 note
※［＃「特のへん＋廴＋聿」、第3水準1-87-71］ is written as the character itself, 犍 (U+728D: 犍陀多), 17 times in the text (the
legend's example is kept). Surasura
reads the notation itself (the ruby and notes are not counted as words; the legend and colophon are skipped).

**The 鲁迅 texts** are Wikisource's simplified-character view (zh-hans) of each page, cut to the title, the author and
the text (the page's links, notes and licence box left out). In 风筝, two characters Unicode lacks are shown as the
common ones (像, 谎), as the page itself does; in 从百草园到三味书屋 the particle the page leaves as 著 (缠络著, 睡不著 …)
is written 着, as Simplified writes it (13 times).

The `HighPriority` / `LowPriority` folders are where each file lands (Current: NOW, then Soon); the learner never sees
those names.
